Song Transpose
==============

The same inline ChordPro song rendered with ``:transpose: 2`` — every chord is
shifted up two semitones and displayed transposed in all three formats, while
the stored English source stays untouched.

.. song::
   :transpose: 2

   {title: Transpose Song}
   {key: C}

   {start_of_verse}
   [C]Hello [Am]world
   [F]Line two [G]here
   {end_of_verse}
